# Demo Presentation Outline

1. Problem: repetitive support questions and slow agent triage.
2. Solution: RAG chatbot grounded in support documents.
3. Architecture: FastAPI, Docling preprocessing, FastEmbed, Qdrant, LLM provider.
4. Demo: upload PDF, build index, ask question, inspect sources.
5. Security: API-key protection and Azure secret configuration.
6. Monitoring: metrics, RAG summary, logs with request ids.
7. Evaluation: question dataset, report, MLflow tracking.
8. Azure deployment: App Service container, ACR, Qdrant Cloud.
9. Business impact: faster answers, deflection, improved consistency.
10. Roadmap: Blob Storage, Application Insights, Azure AD, support connectors.
