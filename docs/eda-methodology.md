# Support Data EDA Methodology

Because production support data is user-provided, this project includes an EDA methodology rather than private data.

Recommended analysis:

- Count tickets/documents by product, issue category, priority, and date.
- Identify top recurring intents and keywords.
- Measure answer coverage: how many frequent questions have documentation.
- Review average ticket resolution time and escalation rate by topic.
- Detect stale docs by comparing ticket frequency against document update age.

Deliverables to generate for a real dataset:

- Topic distribution chart.
- Common query/intent table.
- Documentation coverage table.
- Response effectiveness baseline using historical solved tickets.
- Data quality notes for missing, duplicated, or noisy records.
