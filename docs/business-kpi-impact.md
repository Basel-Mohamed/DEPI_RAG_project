# Business KPI Impact Analysis

Primary KPIs:

- Ticket deflection rate.
- First response time.
- Average handle time.
- Escalation rate.
- Customer satisfaction score.
- Agent productivity.

Measurement plan:

- Compare common-question volume before and after chatbot launch.
- Track chatbot answer success and fallback rate.
- Sample conversations for groundedness and source quality.
- Monitor latency and error rate against service objectives.
- Review support-team feedback for missing documentation.

Expected impact:

- Faster response for repeat questions.
- Lower agent workload on documented policies.
- More consistent answers with source citations.
- Better documentation gap visibility from failed/fallback queries.
